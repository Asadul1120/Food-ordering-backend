## Setup

Dependencies and Prisma Client were installed/generated by NEPBS. Update the database URL in `.env` if needed.

```env
DATABASE_URL="postgresql://postgres:your_password@localhost:5432/your_database?schema=public"
```

Create/sync the database:

```bash
npm run prisma:migrate -- --name init
```

## Request validation

Zod and a reusable request validator are included. Validate a request body by adding the middleware to a route:

```js
import { validateRequest } from "./middleware/validateRequest.js";
import { createUserSchema } from "./validations/user.schema.js";

router.post("/users", validateRequest(createUserSchema), createUser);
```

Inside the handler, read the parsed body from `req.body`.
